Daylily: Interactive 3D AI Sales Assistant for E-commerce

I developed Daylily: Interactive 3D AI Sales Assistant, a powerful Shopify application designed to transform e-commerce customer engagement through an interactive 3D AI avatar. This app combines advanced AI, real-time product memory, and intelligent analytics to help merchants drive more conversions and improve customer experiences.

The platform features a fully interactive avatar built using Heygen, which acts as a virtual sales representative. Natural language understanding powered by Langbase enables human-like conversations with customers, while the system uses memory modules to deeply understand and memorize each store's product catalog and customer interactions.

Built with modern web technologies including React.js, Node.js, and MongoDB, Daylily provides a comprehensive solution for e-commerce automation with advanced AI capabilities and seamless Shopify integration.

Key Features of Daylily AI Sales Assistant

The Daylily platform includes a comprehensive set of features designed to provide an immersive and effective e-commerce experience through AI-powered customer engagement.

  • 3D AI Avatar Assistant

    Fully interactive avatar built using Heygen, which acts as a virtual sales representative. Natural language understanding powered by Langbase enables human-like conversations with customers for personalized shopping experiences.

  • Product Memory & Personalization

    Uses Langbase memory modules to deeply understand and memorize each store's product catalog and customer interactions. Provides personalized product recommendations and targeted upselling suggestions based on user behavior.

  • Shopify Integration

    Seamless installation via Shopify Embedded App SDK and OAuth. Real-time product data synchronization using Shopify Storefront and Admin APIs for comprehensive e-commerce functionality.

Advanced Business Features

Daylily leverages cutting-edge technologies to provide a robust and scalable e-commerce automation platform with advanced AI capabilities and intelligent business logic.

  • Custom Billing Logic

    Micro-interactions under 1 minute are charged at $0.10 per interaction. Interactions longer than 1 minute are billed at $0.20 per minute. Automatic 2% commission deduction on successful product purchases as success fees.

  • Advanced Admin Dashboard

    Accessible via dedicated admin portal with comprehensive analytics. Real-time session tracking, conversion metrics, revenue impact reports, and exportable data for business analysis and decision-making.

  • Mobile-Responsive Design

    Fully mobile-responsive ensuring a consistent experience across all devices. Built-in fallback logic to ensure smooth performance even during API or AI service interruptions.

Technology Stack and Development Architecture

Daylily is built using modern web technologies and cloud services to ensure optimal performance, scalability, and reliability for e-commerce AI automation.

  • Frontend Technologies

    React.js for dynamic user interface components, Three.js for 3D avatar rendering, Tailwind CSS for modern styling, and comprehensive mobile-responsive design for optimal user experience across all devices.

  • Backend Technologies

    Node.js and Express.js for robust server-side functionality, MongoDB for flexible data storage, and comprehensive integration with Shopify APIs for seamless e-commerce functionality.

  • AI & Deployment

    Langbase for conversation intelligence and memory-based product personalization, Heygen for lifelike speaking avatars, AWS and Vercel for scalable cloud deployment, and comprehensive Shopify integration with OAuth.
